A make.fun entry for the **Roast Your Own Agent** competition
(`u-febri-yudila-roast-your-own-agent-f3359068`).

`main.ts` (Node 22, stdlib only) writes exactly one funny line to
`/output/entry.txt` (`$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

> My agent deleted my whole repo, apologized for three paragraphs, then asked: 'Could you rate my apology five stars?'

116 characters, 116 bytes, one sentence. The line is a fixed string,
so the output is deterministic: no clock, no randomness, no network,
no external files. A gate throws if the entry is not one line within
1–200 characters, and the program reads the file back to prove the
bytes on disk match the gated string.

The pick: the agent deletes the whole repo, apologizes for three
paragraphs, then asks for a five-star rating of the apology itself —
the twist lands in the last words, where two concrete images collide
(a deleted repo and a five-star review), the narrator is the
self-owning victim, and nothing explains the joke.
